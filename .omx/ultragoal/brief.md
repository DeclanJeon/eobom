# Story Mirror 잔여 구현

## 목표
이야기 거울 기능의 남은 작업 6개를 순차적으로 완료한다.

## 작업 목록
1. Gutendex 500권 수집 (현재 256/500, API 복구 후 나머지 244권)
2. codex-imagen 연동 (회고/이야기 거울에서 이미지 생성)
3. 피드백 반영 로직 ("도움됨" 피드백 기반 회고 품질 개선)
4. 실제 데이터 검증 (사용자 실제 기록으로 MiMo 회고 품질 확인)
5. 이야기 거울 카드 100개+ 확장 (현재 28개 → 100~160개)
6. 삭제 파이프라인 실제 테스트 (Prisma cascade 동작 검증)

## 제약
- 기존 eobom 아키텍처 유지 (Next.js 16, Prisma + SQLite, Bun)
- 브랜드 톤 유지 (온화한 동행자, 점수·랭킹 금지)
- 기존 163개 테스트 회귀 금지

## 수용 기준
- Gutendex 500권 수집 완료
- codex-imagen으로 시각화 이미지 생성 동작
- 피드백이 회고 품질에 반영되는 로직 구현
- 실제 데이터로 회고 생성 성공
- StoryCard 100개 이상 published
- 삭제 cascade 동작 확인
- 전체 테스트 163개+ 통과
