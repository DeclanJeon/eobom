# 이어봄 v1.3.0

- 날짜: 2026-08-03
- 기준: GitHub main 커밋 이력 (2026-07-27 ~ 2026-08-03)
- 버전 정책: 날짜·기능 묶음 기준으로 정리한 첫 명시 버전

### 기능

- 돌아보기 거울 서사: 4막 상세, spine 목차, 1인칭 목록 얼굴, AI 서사 계약
- 회고 AI 안정화: MiMo 타임아웃·재시도, DeepSeek fallback provider
- 제안하기(`/suggest`): 기능 추가·개편·개선 제안을 문의 파이프라인으로 접수
- 묵상 작성 UX: 초안 초기화, 에디터 포커스 시 placeholder 숨김
- 함께 피드 Threads형 문장·사진 나눔, 기록별 공개/비공개
- 이야기 거울 RAG·시각화·코퍼스 확장(성경 인물·민담·설화·고전)

### 개선

- 디자인 토큰·인터랙션 단일 소스, 네비/페이지네이션 계약 정리
- 오늘 홈 말씀·결단·최근기록 중심으로 단순화
- 성구 라벨 정직화, 새 말씀 추천 중복 제거
