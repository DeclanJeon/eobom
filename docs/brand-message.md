## A. 브랜드 (밖에서 쓰는 말만)

### 고정 2줄

| 층 | 문장 | 쓰는 곳 |
|----|------|---------|
| **공식** | 흩어진 묵상을 이어, 어제의 믿음이 오늘의 방향이 되게 한다. | SEO, OG, README, 키링 |
| **약속** | 모이고, 다시 보이고, 함께 가벼워진다. | 랜딩 서브, 소개 |

**짧은 히어로:** 흩어진 묵상을 잇다  
**이름 울림:** 이어서, 다시 보다.

### 대내용 철학 (히어로 전면 금지)

> 의·선·사랑을 위해 말씀을 쌓고, 나누고, 감사하며 서로의 짐을 함께 진다.  
> 제품의 **첫 약속**은 그 전체가 아니라 — **흩어진 묵상을 모아 어제와 오늘을 잇는 것**이다.

AI는 **거울**이지 재판관이 아니다.  
나눔은 **동행**이지 솔루션 창구가 아니다.

### 세 동작 (제품 뼈대)

```text
모으다  →  잇다  →  나누다
(기록)    (회고)    (함께)
```

다음 깊이(아직 약속하지 않음): **보다**(여정 시각화) · **살다**(결단·감사 되돌아보기) · **이야기 거울**(고전·인물 모티프)

### 화면 한 줄

| 화면 | 문장 |
|------|------|
| 랜딩 | 흩어진 묵상을 잇다 |
| 오늘 | 오늘 머문 말씀이, 내일의 나를 만납니다. |
| 기록 | 하루의 고백이 쌓여 여정이 됩니다. |
| 회고 | 평가가 아니라, 기록이 비추는 거울입니다. |
| 함께 | 나눌 한 문장으로, 서로의 짐을 조금 덜어 줍니다. |

### 보이스

- 온화·단정한 동행자 (코치·판사·인플루언서 아님)
- 사용: 잇다, 모으다, 머무르다, 비추다, 쌓임, 결, 동행, 초안
- 금지: 점수·등급·“하나님이 원하시는 것”·솔루션·랭킹·부족한 믿음

### 제거·금지

- 랜딩 카드의 **스카이 블루** (`#e1f3fe`) — 팔레트 밖, 웰니스 앱 톤
- Primary 위 **연한 골드 본문** (대비율 실패)
- 게이지·연속일수 불·네온 차트
- 모바일 active = clay 닷 / 데스크톱 = forest fill **불일치** → active = forest + gold hairline 으로 통일

### 타이포

| 용도 | 폰트 |
|------|------|
| UI·라벨·네비 | Manrope (sans) |
| 묵상 본문·인용·저널 제목 | Source Serif 4 |
| 디스플레이 헤드 | Sans semibold (가독) + 브랜드명만 Serif 가능 |

### 컴포넌트 규칙

1. **카드** — `paper-card`, 보더 `line`, 그림자 ambient 한 단계만  
2. **CTA** — Primary = forest 채움 / Secondary = 흰 배경 + line / 강조 텍스트 링크 = leaf  
3. **칩** — 기본 white / 성구·귀중 = `chip-gold` (gold-ink) / 함께 태그 = soft chip  
4. **기록 여백** — `writing-margin` 골드 세로선 = “쌓임의 빛”  
5. **다크 회고 카드** — forest 그라데이션 + white 텍스트 유틸 (`text-on-dark*`)만  
6. **함께** — `surface-shared`(mist) + clay를 반응 hover에만  
7. **모션** — 200–400ms, reduce-motion 존중. 랜딩 orb는 유지하되 본 앱 셸은 정숙  

### UX 원칙 (철학 → 인터랙션)

| 원칙 | UI |
|------|-----|
| 모으다 | 2분 기록, 성구 선택 우선, 초안 자동저장 고지 |
| 잇다 | 회고는 “초안/거울” 라벨, 근거 entry 링크 |
| 나누다 | 시트 작성, 원문 비공개 고지, 얕은 반응 4종 |
| 서두르지 않음 | 빈 상태 비난 없음, 점수 없음 |
| 귀중함 | gold-ink eyebrow, 저장 완료 마이크로카피 |
