| 문제 | 상세 |
|------|------|

## 1. 개선된 회고 구조

### 1.1 기존 12개 섹션 → 8개 섹션으로 통합

| 기존 | 변경 |
|------|------|
| 이 기간의 한 문장 | → **한 문장** (유지) |
| 자주 나타난 주제 | → **주제와 마음** (통합) |
| 반복해서 드러난 마음 | ↑ |
| 붙잡고 있던 질문 | → **이야기와 연결** (신규: 고전 인물/비유 연결) |
| 말씀과 삶의 연결 | → **다시 읽을 말씀** (강화: AI 추천) |
| 이전 결단의 흐름 | → **결단의 흐름** (강화) |
| 달라진 점 | → **성찰과 변화** (통합) |
| 다시 읽어볼 기록 | → **다시 읽을 기록** (유지) |
| 작은 실천 | → **다음 한 걸음** (강화: 구체적 실천) |
| 분석의 한계 | → **한계와 안내** (유지) |

**신규 추가:**
- **이야기와 연결** — 사용자의 주제와 겹리는 고전 인물·비유·교훈
- **마음가짐** — 이 기록 앞에서 필요한 태도
- **기도로 이어가기** — 기도 제목 제안

### 1.2 상세 섹션 설계

#### A. 한 문장
> "이 기간에는 N개의 기록이 쌓였고, [핵심 주제]에 대한 성찰이 이어졌습니다."

#### B. 주제와 마음
- 자주 나타난 주제 (근거 포함)
- 반복되는 감정 패턴
- 주제 간 관계 설명

#### C. 이야기와 연결 (신규)
사용자의 주제와 겹치는 고전 인물/비유/교훈을 연결:

```
당신의 기록에서 '빚진 자의 마음'이 나타납니다.
이 주제는 바울이 로마서에서 풀어낸 '빚진 자의 마음'과 닮아 있습니다.

또한, 탕자의 비유(누가복음 15)에서 돌아온 아들이 느낀
책임감과 은혜의 무게도相似한 맥락입니다.

이 이야기들은 '빚을 갚는 삶'이 무엇인지에 대해
서로 다른 관점을 제공합니다.
```

- 연결된 이야기 2~3개
- 각 이야기가 보여주는 관점
- 이야기가 사용자의 상황과 어떻게 겹치는지

#### D. 다시 읽을 말씀
- 주제와 연결된 성경 본문 2~3개
- 각 본문의 읽는 이유
- "이 본문을 읽을 때 주목할 점"

#### E. 결단의 흐름
- 이전 기록에서 나타난 결단
- 결단이 실천되었는지, 어떤 변화가 있었는지
- 아직 남아있는 결단

#### F. 성찰과 변화
- 달라진 점
- 아직 알 수 없는 점
- 앞으로 주목할 점

#### G. 다음 한 걸음 (강화)
- 구체적 실천 1~2개 (모호하지 않게)
- 기도로 이어가기 (기도 제목 제안)
- "오늘 기록할 때 생각해 볼 질문"

#### H. 한계와 안내
- AI 한계 고지
- 공동체·상담·전문가 도움이 필요한 경우 안내

## 2. AI 프롬프트 개선

### 2.1 현재 프롬프트 문제

현재 `mimo.ts`의 프롬프트가 너무 단순함:
- 기록 요약만 요청
- 섹션별 상세 지시사항 없음
- 이야기 연결 요청 없음
- 다음 단계 안내 요청 없음

### 2.2 개선된 프롬프트 구조

```
당신은 한국 기독교 묵상 앱의 회고 도우미입니다.

규칙:
- "~입니다" 서술형만 사용. 판정 금지.
- "하나님이 원하신다" "하나님이 말씀하신다" 금지.
- 기록에 없는 사실을 추론하지 않는다.
- 상충하는 기록이 있으면 둘 다 표시한다.
- 근거 없는 해석 금지.
- 기도·상담·전문가 도움이 필요한 경우 안내한다.

출력 구조 (JSON):
{
  "oneSentence": "한 문장 요약",
  "themes": [{ "key": "주제", "body": "설명", "evidence": [...], "confidence": "high|medium|low" }],
  "emotions": [{ "key": "감정", "body": "설명", "evidence": [...], "confidence": "high|medium|low" }],
  "questions": [{ "key": "질문", "body": "설명", "evidence": [...] }],
  "storyConnections": [{ "story": "이야기 제목", "source": "출처", "connection": "연결 이유", "differentPerspective": "다른 관점" }],
  "scriptureReadings": [{ "ref": "성구", "reason": "읽는 이유", "focus": "주목할 점" }],
  "actionFlow": [{ "key": "결단", "body": "설명", "evidence": [...] }],
  "changeSummary": "달라진 점과 알 수 없는 점",
  "nextSteps": [{ "action": "구체적 실천", "reason": "이유" }],
  "prayerPrompts": [{ "topic": "기도 주제", "suggestion": "기도 내용 제안" }],
  "limitations": "분석 한계"
}

사용자 기록:
{entries}

이 회고는 다음을 포함해야 한다:
1. 기록에서 반복되는 주제와 감정 (근거 포함)
2. 주제와 겹치는 고전 인물·비유·교훈 2~3개 (어떤 관점을 보여주는지 포함)
3. 주제와 연결된 성경 본문 2~3개 (읽는 이유 포함)
4. 이전 결단의 흐름
5. 달라진 점과 아직 알 수 없는 점
6. 구체적 다음 실천 1~2개
7. 기도로 이어갈 주제 1~2개
```

## 3. 빈 섹션 해결

### 3.1 원인 분석

| 빈 섹션 | 원인 | 해결 |
|---------|------|------|
| 반복된 마음 | AI가 emotion을 비워서 반환 | 프롬프트에서 감정 분석 명시적 요청 |
| 붙잡은 질문 | AI가 question을 비워서 반환 | 프롬프트에서 질문 추출 명시적 요청 |
| 말씀 연결 | AI가 scriptureConnections을 비워서 반환 | 프롬프트에서 성경 연결 명시적 요청 |
| 결단 흐름 | AI가 actionFlow을 비워서 반환 | 프롬프트에서 결단 흐름 명시적 요청 |

### 3.2 프롬프트에서 각 섹션을 명시적으로 요청

현재 프롬프트에는 "이 항목들을 모두 작성하라"는 지시가 없음.
개선된 프롬프트에서는 각 섹션을 명시적으로 요청하고, 빈 값을 반환하면 재생성하도록 한다.

## 4. 이야기 연결 (이야기 거울 연계)

### 4.1 회고에서 이야기 거울로의 연결

회고의 "이야기와 연결" 섹션에서 고전 인물을 소개하고,
상세 페이지에서 "이야기 거울"로 연결한다.

### 4.2 연결 방식

1. 회고에서 주제 추출
2. StoryCard 테이블에서 해당 주제와 겹치는 카드 검색
3. 상위 2~3개를 "이야기와 연결" 섹션에 표시
4. 각 이야기에 "더 읽기 →" 링크 (이야기 거울 상세 페이지)

### 4.3 구현

`mimo.ts`의 회고 프롬프트에 StoryCard 목록을 포함하여,
AI가 적절한 이야기를 선택하도록 한다.
